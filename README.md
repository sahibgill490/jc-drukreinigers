# J.C. Drukreinigers — GitHub Pages upload

This is a **standalone static website**. It does not need Node.js, React, a build command, or a server.

## Upload it to GitHub Pages

1. In GitHub, select **New repository** and create a public repository such as `jc-drukreinigers`.
2. Upload everything in this folder, including `index.html` and the complete `assets` folder. Do not put the files inside an extra nested folder.
3. Open the repository’s **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**. Select the `main` branch and the `/ (root)` folder, then click **Save**.
5. Wait a few minutes. GitHub will show the new website address at the top of the Pages settings screen. It will usually look like `https://YOUR-USERNAME.github.io/jc-drukreinigers/`.
